SHADOW TALES STUDIO - FREE FOUNDATION V1

Files included:
- index.html: app screen
- style.css: mobile-first design
- app.js: projects, character library, script duration, approvals, backup/restore
- manifest.json, sw.js, icon.svg: PWA install/offline support

PUBLISH ON GITHUB PAGES:
1. Open your GitHub repository in Chrome.
2. Tap Add file > Upload files.
3. Upload ALL files from this folder (including README.txt).
4. Commit changes to the main branch.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages deployment. Open the URL shown on that Pages screen.
9. On Android Chrome use menu > Add to Home screen / Install app.

IMPORTANT:
This foundation does not yet generate AI images, voices or animation videos.
It stores projects in the browser's local storage. Use Backup & Restore regularly.
