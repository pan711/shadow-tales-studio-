SHADOW TALES STUDIO - FOUNDATION V2

Includes:
- Projects and script workspace
- Asset Library for humans, animals, vehicles, fantasy creatures, locations, objects and robots
- 2D/3D style labels and reusable asset records
- Optional small reference image stored in browser localStorage
- Production checklist, duration estimate, backup and restore
- PWA manifest and offline service worker

IMPORTANT:
This is a working planning/library foundation. It does NOT yet generate actual AI images, rigged 3D models, animation, voice or complete videos. Those require separate generation tools/services and may have free-tier limits.
Data is stored locally in the browser. Download backups regularly. Large images can fill browser storage; use images around 1.5 MB or smaller.

Upload the contents of this folder to the root of the GitHub repository and commit to main.
